Tabs

Navegação local entre seções relacionadas de uma mesma página. O componente é genérico, acessível, controlável externamente e renderiza apenas o painel selecionado.

Como usar

Propriedades

Input / Output Tipo Padrão Descrição
activeTabId string '' Identificador da tab ativa controlado pelo consumidor
ariaLabel string 'Seções' Nome acessível do tablist
activeTabChange output string - Emitido quando o usuário seleciona uma tab diferente
aq-tab id required string - Identificador estável da tab
aq-tab label required string - Texto exibido no cabeçalho
aq-tab disabled boolean false Remove a tab da navegação e impede seleção
