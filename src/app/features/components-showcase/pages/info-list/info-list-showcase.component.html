Info List

Lista genérica e reutilizável de itens informativos. Exibe uma coleção de InfoListItemData usando o componente aq-info-list-item internamente. Suporta paginação opcional, estados de carregamento e vazio, itens clicáveis e diferentes variações de badge. O componente é agnóstico ao domínio — o consumidor é responsável por converter seus dados para o formato InfoListItemData.

Como usar

Propriedades

Input / Output Tipo Padrão Descrição
items required InfoListItemData[] — Lista de itens a exibir, já convertidos para o formato de UI
paginated boolean true Habilita paginação e exibe o paginador quando há mais itens que o pageSize
pageIndex number 0 Índice da página atual (base 0), controlado externamente
pageSize number 10 Quantidade de itens exibidos por página
pageSizeOptions number[] [5, 10, 20] Opções disponíveis para o seletor de tamanho de página
loading boolean false Exibe o estado de carregamento e oculta a lista
disabled boolean false Desabilita a lista e todos os itens internamente
emptyState { title: string; description?: string } { title: 'Nenhum item encontrado' } Customiza o título e a descrição exibidos quando a lista está vazia
clickable boolean false Torna todos os itens da lista clicáveis com foco via teclado
pageChange output InfoListPageChange — Emitido quando o usuário troca de página ou altera o tamanho de página
itemClick output InfoListItemData — Emitido com o item clicado (apenas quando clickable=true)

Lista sem paginação
