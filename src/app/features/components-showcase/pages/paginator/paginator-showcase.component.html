Paginator

Controle generico para paginar tabelas, cards, listas e grids. O componente nao busca dados: ele exibe o estado atual e emite a intencao de mudanca para o consumidor controlar a colecao.

Como usar

Propriedades

Input / Output Tipo Padrao Descricao
page number | null null Pagina publica atual, iniciada em 1.
pageSize number 10 Quantidade de itens por pagina.
totalItems number required Total da colecao completa; totalPages e derivado dele com pageSize.
pageSizeOptions readonly number[] [5, 10, 20] Opcoes positivas do seletor; duplicadas e invalidas sao normalizadas.
disabled / loading boolean false Desabilitam controles; loading tambem aplica aria-busy e preserva os valores.
showFirstLastButtons boolean true Controla os botoes de primeira e ultima pagina.
showPageSizeSelector boolean true Controla a exibicao do seletor de itens por pagina.
paginationChange AqPaginationChange output Emite page e pageSize quando o usuario navega ou troca o tamanho.
