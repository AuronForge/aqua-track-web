Card Selection

Grupo de selecao por cards com suporte a modo simples ou multiplo, Reactive Forms, valores genericos, compareWith para objetos, acessibilidade e layout responsivo alinhado ao Design System do AquaTrack.

Como usar

Propriedades

Input / Output Tipo Padrao Descricao
options required readonly CardSelectionOption<T>[] [] Lista ordenada de opcoes exibidas como cards.
label / ariaLabel string '' Nome visivel ou alternativo do grupo para leitores de tela.
hint string '' Texto de apoio associado semanticamente ao fieldset.
errorMessage / errorMessages string | Record<string, string> '' / {} Mensagem unica ou mapa por chave de erro, seguindo o padrao dos formfields.
required / disabled boolean false Replica obrigatoriedade e indisponibilidade do grupo inteiro.
columns number | null null Define um maximo explicito de colunas sem perder o fallback responsivo.
multiple boolean false Alterna entre selecao unica com radios e multisselecao com checkboxes.
options[].iconName / options[].iconPosition string / 'start' | 'end' '' / 'start' Permite exibir um icone Material no inicio ou no fim do card.
compareWith (optionValue: T, selectedValue: T) => boolean Object.is Permite comparar objetos sem depender da mesma referencia.
selectionChange output CardSelectionChange<T> — Emitido apenas quando a selecao realmente muda, com o valor atual e as opcoes ativas.

Acessibilidade e teclado

O componente usa fieldset, legend e inputs nativos. No modo simples, utiliza radios; no multiplo, checkboxes. Tab entra no grupo, setas navegam entre itens habilitados, Espaco e Enter ativam a opcao em foco, Home vai para a primeira opcao habilitada e End vai para a ultima.
