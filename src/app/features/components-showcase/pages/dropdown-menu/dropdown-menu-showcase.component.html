Dropdown Menu

Generic dropdown triggered by any projected content. Supports an optional header slot, a list of menu items with optional icons, dividers, and destructive styles. The placement input controls where the panel opens relative to the trigger.

Como usar

Propriedades

Input / Output Tipo Padrão Descrição
items required DropdownMenuItem[] — Lista de itens do menu. Cada item suporta id, label, icon?, isDestructive?, hasDividerBefore? e disabled?
placement 'bottom-right' | 'bottom-left' | 'top-right' | 'top-left' 'bottom-right' Posicionamento do painel em relação ao trigger
showChevron boolean true Exibe ou oculta o ícone de seta no botão trigger
itemClick output EventEmitter<DropdownMenuItem> — Emitido ao selecionar um item habilitado do menu
