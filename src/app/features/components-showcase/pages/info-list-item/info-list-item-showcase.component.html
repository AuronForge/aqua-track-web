Info List Item

Item de lista informativo genérico e reutilizável para exibição de dados resumidos em formato horizontal. Apresenta um título principal com badge de status opcional, subtítulo descritivo e área direita com valor em destaque e metadado secundário. Suporta estado interativo com foco acessível via teclado, estado selecionado e estado desabilitado. O componente é agnóstico ao domínio e pode ser usado em listas de medições, histórico de eventos, logs, notificações e dashboards.

Como usar

Propriedades

Input / Output Tipo Padrão Descrição
title required string — Identificador ou título principal do item
value required string — Valor principal exibido à direita
subtitle string '' Texto descritivo abaixo do título. Não renderiza quando vazio
metadata string '' Informação secundária abaixo do valor (hora, data, unidade). Não renderiza quando vazio
badge { label: string; status: InfoListItemStatus } | null null Configuração do badge de status. Quando null, o badge não é renderizado
clickable boolean false Torna o item interativo com role="button" e foco via teclado
disabled boolean false Desabilita a interação e aplica opacidade reduzida
selected boolean false Aplica estilo de seleção ativa ao item
itemClick output EventEmitter<void> — Emitido ao clicar ou pressionar Enter/Space (apenas quando clickable=true)

Variações de status

normal — badge success

attention — badge warning

danger — badge error

neutral — badge tertiary

Estado interativo

clickable=true — hover e foco via teclado ativos

clickable=false (default) — apenas informativo

Estado selecionado

selected=true

Estado desabilitado

disabled=true com clickable=true

Campos opcionais

Sem badge

Sem subtitle

Sem metadata

Configuração mínima

Apenas title e value (obrigatórios)

Tamanho controlado pelo consumidor

50% da largura do container
