Input Select

Seletor visual genérico com informações estruturadas por opção — ícone, título e subtítulo. Usa Angular CDK Overlay para posicionamento inteligente do dropdown, com fallback automático de posição (acima quando não há espaço abaixo), viewport margin para mobile e suporte completo a navegação por teclado e leitores de tela.

Como usar

Propriedades

Input / Output Tipo Padrão Descrição
options InputSelectOption[] [] Lista de opções. Cada item suporta id, title, subtitle?, icon? e disabled?
selectedOption InputSelectOption | null null Opção atualmente selecionada. O consumidor controla o estado
placeholder string 'Selecione uma opção' Texto exibido no trigger quando nenhuma opção está selecionada
size 'medium' | 'compact' 'medium' Tamanho do trigger
disabled boolean false Desabilita o componente inteiro, impedindo abertura e interação
loading boolean false Impede abertura do dropdown — use enquanto as opções estão sendo carregadas
selectionChange output InputSelectChangeEvent — Emitido ao selecionar uma opção habilitada. Contém option e previousOption
