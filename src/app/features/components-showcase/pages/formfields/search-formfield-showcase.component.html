Search Formfield

Campo de busca especializado do AquaTrack para filtros textuais, buscas explicitas por formulario e fluxos reativos baseados em `valueChanges`, mantendo CVA, acessibilidade e estados visuais consistentes com os demais formfields.

Como usar

Propriedades

Input / Output Tipo Padrão Descrição
label string '' Label visual opcional do campo.
ariaLabel string tradução interna Nome acessível quando não houver label visível.
placeholder string '' Placeholder contextualizado definido pelo consumidor.
hint string '' Texto auxiliar exibido enquanto não houver erro visível.
showClearButton boolean true Controla a ação de limpar quando houver valor.
loading boolean false Exibe estado de carregamento sem apagar o termo atual.
clearAriaLabel / loadingLabel string tradução interna Rótulos acessíveis customizáveis para limpar e carregar.
required / disabled / readonly boolean false Estados nativos refletidos também na acessibilidade.
errorMessages Record<string, string> {} Mensagens personalizadas por chave de validação.
cleared output void — Emitido quando o usuário limpa explicitamente o campo.
focus() () => void — Foca programaticamente o input interno.
