Text Formfield

Campo textual reutilizável do AquaTrack para formulários com Reactive Forms. Centraliza label, hint, erro, prefixos, sufixos, ações por ícone e suporte opcional a senha com toggle, mantendo acessibilidade e estados visuais consistentes.

Como usar

Propriedades

Input / Output Tipo Padrão Descrição
label required string — Label visível e associada semanticamente ao input
placeholder string '' Texto de apoio opcional dentro do campo
hint string '' Mensagem auxiliar exibida enquanto não houver erro visível
type 'text' | 'password' | 'email' | 'search' | 'tel' | 'url' 'text' Tipo nativo do input
prefixText / suffixText string undefined Texto contextual exibido antes ou depois do valor
prefixIcon / suffixIcon string undefined Nome do ícone Material decorativo em prefixo ou sufixo
actions FormfieldAction[] [] Ações clicáveis no prefixo ou sufixo com ariaLabel obrigatório
passwordToggle boolean false Habilita a ação interna de mostrar/ocultar senha quando type="password"
errorMessages Record<string, string> {} Mapa de mensagens personalizadas por chave de erro
actionClick output FormfieldAction — Emitido ao clicar em uma action habilitada
