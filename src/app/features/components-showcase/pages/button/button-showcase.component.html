Button

Componente de botão aplicado como diretiva em elementos nativos button ou a. Suporta quatro variantes (flat, stroked, basic, icon), seis cores e três tamanhos. O conteúdo é projetado via ng-content, permitindo combinar ícone e texto livremente.

Como usar

Propriedades

Input Tipo Padrão Descrição
variant 'flat' | 'stroked' | 'basic' | 'icon' 'flat' Estilo visual do botão
color 'primary' | 'secondary' | 'tertiary' | 'success' | 'error' | 'warning' 'primary' Esquema de cor aplicado
size 'small' | 'medium' | 'large' 'medium' Tamanho do botão
