Alert

Alerta inline, persistente e contextual para orientacoes, avisos, confirmacoes e erros que precisam permanecer no fluxo da tela enquanto forem relevantes.

Como usar

Propriedades

Input / Output Tipo Padrao Descricao
variant 'info' | 'success' | 'warning' | 'error' | 'neutral' 'info' Define tom visual, icone padrao e semantica acessivel.
title string | undefined undefined Titulo opcional exibido antes do conteudo projetado.
icon string | undefined icone da variante Nome do Material Icon usado para substituir o icone padrao.
showIcon boolean true Controla a exibicao do icone sem remover a semantica textual.
dismissible boolean false Exibe o botao de fechar e permite o consumidor remover o alerta.
ariaLabel string | undefined undefined Nome acessivel opcional quando o contexto visual nao e suficiente.
dismissed output void - Emitido quando o usuario aciona o fechamento.

Responsividade

Container estreito e texto longo

Nao foi possivel salvar a medicao porque alguns parametros obrigatorios ainda precisam ser revisados. Confira temperatura, pH, amonia, nitrito e nitrato antes de tentar novamente.

Acessibilidade

Variantes error e warning usam role="alert" e aria-live="assertive".

Variantes info, success e neutral usam role="status" e aria-live="polite".

O icone e decorativo; o significado deve estar tambem no titulo ou na mensagem.
