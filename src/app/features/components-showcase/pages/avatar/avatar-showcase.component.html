Avatar

Componente de avatar em três variantes: iniciais (padrão), circular com imagem e ícone. Suporta três cores (primary, secondary, tertiary) e três tamanhos (small, normal, large).

Como usar

Propriedades

Input Tipo Padrão Descrição
variant 'initials' | 'circular' | 'icon' 'initials' Modo de exibição do avatar
color 'primary' | 'secondary' | 'tertiary' 'primary' Cor de fundo do avatar
size 'small' | 'normal' | 'large' 'normal' Tamanho do avatar
initials string '' Texto exibido na variante initials (máx. 3 caracteres)
src string '' URL da imagem na variante circular
alt string '' Texto alternativo da imagem (acessibilidade)
icon string '' Nome do ícone Material na variante icon
