Chip

Componente de chip presentacional para exibição de status e categorias. Possui um dot indicator colorido que acompanha o label, reforçando o significado visual. Suporta três variantes (filled, outlined, tinted), sete cores e dois tamanhos. O conteúdo é projetado via ng-content.

Como usar

Propriedades

Input Tipo Padrão Descrição
variant 'tinted' | 'filled' | 'outlined' 'tinted' Estilo visual do chip
color 'primary' | 'secondary' | 'tertiary' | 'success' | 'warning' | 'error' | 'information' 'primary' Esquema de cor aplicado
size 'small' | 'medium' 'small' Tamanho do chip
disabled boolean false Desabilita e aplica opacidade reduzida
