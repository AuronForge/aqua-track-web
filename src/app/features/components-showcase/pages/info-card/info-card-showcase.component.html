Info Card

Card informativo genérico e reutilizável para exibição de dados resumidos. Suporta ícone opcional, badge de status com duas variações semânticas (attention e stable), título, subtítulo, linha divisória e uma lista dinâmica de métricas com label e valor. Todo conteúdo textual é fornecido pelo consumidor, tornando o componente agnóstico ao domínio e compatível com múltiplos idiomas.

Como usar

Propriedades

Input / Output Tipo Padrão Descrição
title required string — Título principal do card
status 'stable' | 'attention' 'stable' Define a cor semântica do badge de status
statusLabel string '' Texto exibido dentro do badge de status
icon string '' Nome do ícone Material exibido no cabeçalho
iconFamily string 'material-icons-outlined' Classe CSS da família de ícones
subtitleLabel string '' Rótulo da linha de subtítulo
subtitleValue string '' Valor exibido ao lado do rótulo de subtítulo
metrics InfoCardMetric[] [] Lista de métricas { label, value } no rodapé do card
clickable boolean false Torna o card interativo com role="button" e foco via teclado
fillContainer boolean false Expande o card para preencher a altura do container pai
cardClick output EventEmitter<void> — Emitido ao clicar no card (apenas quando clickable=true)

Clickable

clickable=true — interativo, focável via teclado

clickable=false (default) — apenas informativo
