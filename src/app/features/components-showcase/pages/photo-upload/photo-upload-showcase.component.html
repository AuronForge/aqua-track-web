Photo Upload

Dropzone genérico para fotos e imagens com clique, drag and drop, validação de formato e tamanho, preview opcional e emissão de FormData pronta para qualquer API.

Como usar

Propriedades

Input / Output Tipo Padrão Descrição
accept string 'image/jpeg,image/png,image/webp' Lista de MIME types ou extensões aceitas
maxFileSizeBytes number 5242880 Tamanho máximo permitido para o arquivo
fieldName string 'file' Nome da chave usada no FormData emitido
showPreview boolean false Exibe um preview local da imagem selecionada
errorMessage string | null null Permite mostrar um erro vindo da API ou do contexto consumidor
fileSelected output File — Emitido quando um arquivo válido é selecionado
formDataSelected output FormData — Entrega o payload pronto para enviar com HttpClient
fileRejected output PhotoUploadRejection — Informa o motivo da rejeição quando a validação local falha
