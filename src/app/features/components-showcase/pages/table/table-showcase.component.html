Table

Tabela generica para dados estruturados, historicos e listagens administrativas. O componente cuida de estrutura, estados, ordenacao, selecao, responsividade e acessibilidade; conteudos especificos ficam com o consumidor via templates.

Como usar

Propriedades

Input / Output Tipo Padrao Descricao
rows readonly T[] required Registros renderizados pela tabela.
columns AqTableColumn<T>[] required Configuracao de colunas, alinhamento, largura, ordenacao e prioridade responsiva.
sort AqTableSort | null null Estado de ordenacao controlado externamente.
selectable boolean false Habilita coluna de checkbox com selecao unica ou multipla.
rowClickable boolean false Torna linhas acionaveis por mouse, Enter e Space.
density 'comfortable' | 'compact' 'comfortable' Controla a altura das linhas sem remover foco ou area minima de interacao.
sortChange AqTableSort | null output Emitido quando uma coluna ordenavel e acionada.
