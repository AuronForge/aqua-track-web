Toolbar

Barra de navegação superior da aplicação. Exibe a marca AquaTrack, o título e subtítulo da página atual, uma área central opcional para filtros ou ações contextuais, o seletor de idioma e o menu do usuário com avatar e informações da conta.

Como usar

Propriedades

Input / Output Tipo Padrão Descrição
showBrand boolean true Exibe ou oculta o bloco de marca da toolbar
pageTitle required string — Título da página exibido na toolbar
pageSubtitle string '' Subtítulo opcional exibido abaixo do título
userName required string — Nome completo do usuário exibido no menu
userEmail required string — E-mail do usuário exibido no menu
userInitials required string — Iniciais exibidas no avatar do usuário
userAvatarColor 'primary' | 'secondary' | 'tertiary' 'primary' Cor de fundo do avatar do usuário
selectedLanguage required 'pt' | 'en' | 'es' — Idioma selecionado no switcher de idioma
userMenuItems required DropdownMenuItem[] — Itens exibidos no menu dropdown do usuário
center slot content projection vazio Área opcional entre o título e as ações para filtros, tabs ou CTAs contextuais
languageChange output EventEmitter<'pt' | 'en' | 'es'> — Emitido ao trocar o idioma no switcher
userMenuItemClick output EventEmitter<DropdownMenuItem> — Emitido ao clicar em um item do menu do usuário
